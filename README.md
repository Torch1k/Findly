# Findly


**Findly** — веб-приложение для поиска и подбора специалистов.

Платформа позволяет пользователям создавать профили, публиковать свои резюме и указывать профессиональные навыки, чтобы работодатели могли находить подходящих кандидатов.

## Features
- Создание профиля
- Публикация резюме
- Просмотр кандидатов
- Поиск специалистов
